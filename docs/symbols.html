WristWake · Pebble Time 2

Wecker-Symbole

Alle 30 Symbole, die ein Wecker in WristWake bekommen kann: so sieht die Kachel auf der Uhr aus, und so erscheint der Wecker in Home Assistant. Sortiert wie in der Auswahl auf der Uhr (deutsch, A–Z).

Groß 36 px: Klingel-Bildschirm, Auswahl, Menüzeile Klein 18 px: Wecker-Liste, Kopfzeile Hell / Dunkel: Hintergrund des Farbschemas Home Assistant: Wert von symbol und Icon am Sensor
Die Farben sind so dargestellt, wie das Display der Pebble sie zeigt (etwas blasser als am Bildschirm). Liegt eine Kachel auf einer gleichen oder sehr ähnlichen Hintergrundfarbe, bekommt sie automatisch einen dünnen Rahmen.
Ohne Symbol zeigt Home Assistant mdi:alarm, bei ausgeschaltetem Wecker mdi:alarm-off.
